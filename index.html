About

I didn't start with a perfect plan. I started by showing up.

I did not start in tech with a perfect plan. I started because I wanted a better future, and I kept showing up every day to learn.

I'm Temple Stephen, a Cloud and DevOps Engineer in training from Nigeria. I learn by building real projects, breaking things, fixing them, and writing down everything I learn along the way. Every project in this portfolio came from that process, not from copying a tutorial.

So far I have built an AWS 3-Tier Task Manager, a CI/CD pipeline with Jenkins and Docker, serverless AWS projects, and cloud deployments that taught me how real applications move from code to production. I enjoy solving problems, automating repetitive work, and making deployments simple and reliable.

I am still learning, but I am proud of how far I have come and excited about what I will build next. This portfolio is a record of that growth, and the work I am doing to become a Cloud and DevOps Engineer.
