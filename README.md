## 🔵🟢 Jenkins Blue-Green CI/CD

A hands-on CI/CD project designed to demonstrate **zero-downtime application deployment** using Jenkins, Docker, Nginx, and Blue-Green deployment principles.

### Deployment Workflow

```text
Developer
    │
    ▼
  GitHub
    │
    ▼
  Jenkins
    │
    ├── Build
    ├── Test
    └── Docker Build
          │
          ▼
     Deploy GREEN
          │
          ▼
     Health Check
       /       \
    PASS       FAIL
     │           │
     ▼           ▼
Switch       Keep BLUE
Traffic      / Rollback
     │
     ▼
GREEN Live
```

### Key Features

* Jenkins CI/CD pipeline
* Docker containerization
* Blue-Green deployment
* Nginx traffic switching
* Automated health checks
* Zero-downtime deployment strategy
* Rollback capability
* GitHub integration
* AWS EC2 deployment

🔗 **Repository:**
https://github.com/TempleStephen/jenkins-blue-green-cicd
